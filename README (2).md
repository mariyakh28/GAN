# Balancing Imbalanced Image Datasets Using GANs

A deep learning project that explores how Generative Adversarial Networks (GANs) can help reduce class imbalance in a cat-vs-dog image classification task. It compares a baseline CNN with CNN models trained on datasets augmented using Vanilla GAN and DCGAN-generated cat images.

## Overview

Image datasets with uneven class distributions can cause classifiers to favor the majority class. In this project, the training data contains substantially more dog images than cat images. The project investigates whether synthetic cat images generated by GANs can improve minority-class recognition.

## Models

- **Vanilla GAN** — a basic GAN used to generate synthetic cat images.
- **DCGAN** — a deep convolutional GAN using transposed convolutions and batch normalization in the generator.
- **CNN classifier** — classifies images as cats or dogs and is evaluated under different training-data scenarios.

## Dataset

The code downloads the cat-and-dog dataset with `kagglehub`:

```python
path_c = kagglehub.dataset_download("thienbao1909/dog-cat")
```

The code expects a dataset structure containing `train/cat`, `train/dog`, `test/cat`, and `test/dog` directories (the dataset may contain an additional parent directory named `datasheet cat-dog`).

The accompanying project report describes an imbalanced training set with **1,000 cat images** and **11,008 dog images**. Check the downloaded dataset and actual folder counts before training, as counts may differ by dataset version or preprocessing.

## Workflow

1. Download and inspect the dataset.
2. Resize images to **32 × 32** pixels.
3. Train a baseline CNN on the original training data.
4. Train a Vanilla GAN and a DCGAN to generate synthetic cat images.
5. Save generated images under `project_data/generated/`.
6. Create augmented training folders for the Vanilla GAN and DCGAN experiments.
7. Train CNN classifiers on the augmented datasets.
8. Evaluate the models using accuracy, classification reports, and confusion matrices.
